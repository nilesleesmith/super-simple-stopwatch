# Super Simple Stopwatch

A JavaScript learning project demonstrating how an object can contain both properties and methods.

## About

This project creates a stopwatch object in JavaScript.

The object stores information describing the stopwatch and contains methods that modify its time value.

## Stopwatch Properties

The example object contains properties such as:

- Time
- Color
- Shape
- Owner

## Stopwatch Methods

The object demonstrates methods for:

- Starting or increasing the time
- Stopping or decreasing the time
- Resetting the time to zero

## Running the Project

1. Clone or download the repository.
2. Open `index.html` in a browser.
3. Open the browser developer tools.
4. View the Console to see the stopwatch object and method results.

## Purpose

This project was created as a simple exercise for understanding how JavaScript objects combine related data and behavior.
